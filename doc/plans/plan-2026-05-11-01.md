# Plan 01 - Review Fixups and Autosquash Finalization

## Goal
Make review-round fixups transient by default and require autosquash finalization before merge.

## Dependency Graph
T1 -> T2, T1 -> T3, T2 -> T4, T3 -> T4, T4 -> T5

## Tasks
T1 - Document the new review-round states and fixup policy in `AGENTS.md`, `doc/workflow.md`, and Claude command playbooks.

T2 - Add `scripts/git_autosquash_finalize.sh` to autosquash against `origin/main`, rerun full gates, and force-push with lease.

T3 - Update existing workflow scripts so local reviews create doc fixups and merge refuses PR heads containing autosquashable commits.

T4 - Extend the Python regression suite for finalization, merge guards, local-review fixups, and template-sync coverage.

T5 - Add the new finalizer and regression tests to `scripts/template_sync.sh`.

## Verification

### Properties (must pass)
| Property | Module | Invariant |
|----------|--------|-----------|
| `finalizer_squashes_fixups_before_push` | `tests.test_git_autosquash_finalize` | Code and review-doc fixups are absent from the post-finalization branch and gate commands run before force-push. |
| `merge_guard_rejects_autosquash_commits` | `tests.test_git_merge` | `scripts/git_merge.sh` refuses PR heads that still contain `fixup!`, `amend!`, or `squash!` commits and does not invoke `gh pr merge`. |
| `local_review_commits_doc_fixup` | `tests.test_pr_review` | `scripts/pr_review.sh` appends the review and commits it as a fixup to the finalized-doc commit. |
| `template_sync_carries_finalizer` | `tests.test_template_sync` | The manifest includes the finalizer and its regression tests for downstream sync. |
